# اردو ریسنیٹ — ایس ٹی ایل ۱۰

مکمل اردو ماخذ اور اردو احکام کے لیے نیا
[خود مختار تربیتی راستہ](../../examples/مکمل_اردو/ایس_ٹی_ایل۱۰/README.md)
استعمال کریں۔ یہ فولڈر اصل تاریخی تجربہ محفوظ رکھتا ہے۔ اس کے اصل اعداد اور
تمام چار خاکے [منصوبے کے نتائج](../../docs/نتائج/ریسنیٹ/README.md) میں بھی ہیں۔

یہ مکمل تجربہ اردو پائی میں لکھا گیا ہے: ماڈل، تصاویر کی تیاری، تربیت، جانچ،
پیشگوئی اور گراف۔ اپنی جماعتوں، افعال، ماڈل کی تہوں اور فولڈر کے نام اردو میں
ہیں۔ PyTorch کے لازمی طریقے `__init__` اور `forward` اپنے اصل نام رکھتے ہیں۔

اصل تربیت مکمل: **آزمائشی درستگی ۷۷٫۳۵٪ — ۶٬۱۸۸ / ۸٬۰۰۰ تصاویر**۔
۵۰ دور تقریباً ۲۴ منٹ میں مکمل ہوئے؛ توثیق سے منتخب بہترین checkpoint دور
۴۴ کا ہے، جس کی توثیقی درستگی ۷۷٪ تھی۔ مکمل
[اردو نتائج اور گراف](نتائج/ابتدائی_تربیت/نتائج.md)،
[اصل metrics](نتائج/ابتدائی_تربیت/خلاصہ.json)،
[محفوظ وزن](نتائج/ابتدائی_تربیت/بہترین_وزن.pt) اور
[آزاد جانچ](نتائج/ابتدائی_تربیت/تصدیق.json) دستیاب ہیں۔

## ماڈل اور تجربے کی ترتیب

ریسنیٹ اٹھارہ کی چار منزلیں ہیں؛ ہر منزل میں دو باقیاتی بلاک `[2,2,2,2]` ہیں۔
ہر بلاک میں دو `3×3` پیچشیں، BatchNorm اور ReLU ہیں؛ شکل بدلنے پر `1×1`
راستہ استعمال ہوتا ہے۔ آخر میں adaptive average pooling اور دس جماعتوں کا
درجہ بند ہے۔ چھوٹی تصاویر کے لیے ابتدائی `3×3`، stride 1 پیچش استعمال ہوئی؛
ابتدائی max-pooling ہٹا دیا گیا ہے۔ یہ ImageNet کے `7×7` stem سے واضح فرق ہے۔

اصل GPU تجربہ: **بنیادی چوڑائی ۶۴، ۹۶×۹۶ تصاویر، ۱۱٬۱۷۳٬۹۶۲ پیرامیٹر،
۵۰ دور، بیچ ۶۴، بیج ۴۲**۔ وزن شروع سے سیکھے جاتے ہیں۔ SGD میں momentum
`0.9`، weight decay `0.0005` اور ابتدائی شرح `0.05` ہے؛ شرح cosine schedule
سے کم ہوتی ہے۔ CUDA پر float16/float32 mixed precision اور GradScaler استعمال
ہوتے ہیں۔ وزن float32 میں محفوظ ہوتے ہیں۔

CPU کے لیے CLI کی چھوٹی ابتدائی ترتیب ۲۰ دور، چوڑائی ۱۶ اور ۴۸×۴۸ ہے؛ اصل
GPU نتیجے کی ترتیب نیچے دیے گئے مکمل حکم میں درج ہے۔ دوسری مشین پر یکساں
بیج مفید ہے، مگر CUDA، cuDNN، الگ ہارڈویئر اور نسخوں کے درمیان بٹ بہ بٹ
تکرار کی ضمانت نہیں۔

## اصل اعداد اور منصفانہ جانچ

[سرکاری STL-10](https://cs.stanford.edu/~acoates/stl10/) میں نشان زدہ تربیتی
تصاویر ۵٬۰۰۰ اور آزمائشی تصاویر ۸٬۰۰۰ ہیں، ہر تصویر ۹۶×۹۶ RGB ہے۔ اصل نشان
زدہ تربیتی حصے کی ہر جماعت سے ۴۰۰ تصاویر تربیت اور ۱۰۰ توثیق میں لی جاتی ہیں:

| حصہ | تعداد | استعمال |
|---|---:|---|
| تربیت | ۴٬۰۰۰ | وزن سیکھنا؛ random crop اور افقی پلٹ۔ |
| توثیق | ۱٬۰۰۰ | ہر دور کے بعد جانچ اور بہترین checkpoint کا انتخاب۔ |
| آخری آزمائش | ۸٬۰۰۰ | منتخب checkpoint کی آخری مکمل جانچ۔ |

اوسط اور معیاری انحراف صرف ۴٬۰۰۰ تربیتی تصاویر سے نکلتے ہیں۔ توثیق اور
آزمائش میں augmentation نہیں ہوتا۔ آزمائشی درستگی سے شرح، دور یا ماڈل منتخب
نہیں کیا جاتا۔ یہ ایک مقرر تقسیم کا supervised تجربہ ہے؛ STL-10 کے معیاری
دس fold کے benchmark کا نتیجہ نہیں۔ غیر نشان زدہ تصاویر استعمال نہیں ہوتیں۔

چاروں استعمال شدہ binary فائلوں کی اصل MD5 قدریں نصب شدہ torchvision سے لے
کر الگ جانچی گئی ہیں۔ محفوظہ کے ابتدائی حصے میں یہ چار مکمل فائلیں موجود
تھیں؛ غیر استعمال شدہ unlabeled حصہ حاصل کرنا روک دیا گیا۔ پورے archive کی
تصدیق کا دعویٰ نہیں؛ `ڈیٹاسیٹ/نشان_زدہ_جانچ.json` میں دونوں حالتیں الگ لکھی ہیں۔

## چلانے کا طریقہ

تمام احکام `urdupy` پروجیکٹ کی جڑ سے چلائیں۔ اصل GPU تجربہ:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m urdupy run "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/تربیت.urdu" -- --device cuda --base-width 64 --image-size 96 --epochs 50 --batch-size 64 --threads 6 --output "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/نتائج/نئی_تربیت"
```

موجودہ اصل نتائج `نتائج/ابتدائی_تربیت/` میں ہیں۔ نیا تجربہ ہمیشہ نئے `--output`
میں لکھیں؛ مکمل یا جاری نتیجہ خاموشی سے تبدیل نہیں کیا جاتا۔ پہلے سے جانچ
شدہ اعداد دوبارہ استعمال ہوں گے۔ نئے فولڈر میں اعداد حاصل کرنے کے لیے
`--download` دیں؛ معاون سرکاری محفوظہ حاصل کرکے صرف مطلوبہ فائلیں کھولتا ہے۔

اپنی تصویر کی پہلی تین جماعتیں اور امکانات:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m urdupy run "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/پیشگوئی.urdu" -- "اپنی_تصویر.jpg"
```

فوراً آزمانے کے لیے پہلی اصل آزمائشی تصویر بھی محفوظ ہے:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m urdupy run "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/پیشگوئی.urdu" -- "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/نتائج/ابتدائی_تربیت/نمونہ.png"
```

الگ تازہ process میں یہی حکم کامیاب ہوا؛ پہلی پیشگوئی `گھوڑا` تھی۔ یہ تصویر
صرف اصل index صفر سے منتخب ہوئی، ماڈل کے جواب سے نہیں۔

محفوظ اصل اعداد سے curves، confusion matrix اور فی جماعت گراف دوبارہ بنائیں:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m urdupy run "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/دوبارہ_خاکے.urdu" -- "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/نتائج/ابتدائی_تربیت"
```

تصویری grid اصل تربیت کے آخر میں محفوظ ہوتا ہے؛ دوبارہ خاکے والا حکم صرف
prediction اعداد پڑھتا ہے اور پہلے سے موجود grid محفوظ رہتا ہے۔ grid میں
ہر حقیقی جماعت کی پہلی دو آزمائشی تصاویر ہیں، منتخب صرف کامیاب مثالیں نہیں۔

## ماحول دوبارہ بنانا اور جانچیں

اصل GPU ماحول project-local `.venv-resnet` ہے، جس میں بعض عام packages base
Python سے ملتے ہیں؛ اسے pristine isolated environment نہیں کہا گیا۔ نیا صاف
ماحول بنانا چاہیں تو compatible CPython 3.13 اور اپنے آلے کے مطابق
[سرکاری PyTorch طریقہ](https://pytorch.org/get-started/locally/) استعمال کریں۔
اس Windows/RTX مشین پر اصل CUDA wheels کا حکم:

```powershell
python -m venv .venv-resnet-new
.\.venv-resnet-new\Scripts\python.exe -m pip install torch==2.14.1+cu130 torchvision==0.29.1+cu130 --index-url https://download.pytorch.org/whl/cu130
.\.venv-resnet-new\Scripts\python.exe -m pip install numpy==2.5.4 Pillow==12.3.0 matplotlib==3.11.2 arabic-reshaper==3.0.1 python-bidi==0.6.11
.\.venv-resnet-new\Scripts\python.exe -m pip install .
```

اختیاری تجرباتی جانچیں اور زبان کی اصل جانچیں:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m unittest discover -s "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰" -p "test_*.py" -v
python -X utf8 -m unittest discover -s tests -q
```

مکمل اصل تربیت کے بعد آزاد جانچ کا حکم:

```powershell
.\.venv-resnet\Scripts\python.exe -X utf8 -m urdupy run "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/نتائج_جانچیں.urdu" -- --results "experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/نتائج/ابتدائی_تربیت"
```

یہ معاون اصل binary نشان سے ترتیب اور تعداد، تربیت/توثیق کا الگ ہونا،
منتخب دور، ۸٬۰۰۰ پیشگوئیوں کی درستگی، وزن اور ماخذ کے ہیش، PNG decoding اور
SVG ساخت دوبارہ جانچتا ہے۔ یہ ماڈل دوبارہ نہیں چلاتا اور آزمائشی نتیجے پر
کوئی tuning نہیں کرتا۔ تصویری layout کی نظر سے جانچ اس حسابی جانچ سے الگ ہے۔

چھوٹے مصنوعی CPU fixture میں اس Windows oneDNN build کا convolution backward
رک جاتا تھا؛ متعلقہ test عارضی طور پر native CPU backend استعمال کرتا اور
بعد میں اصل setting بحال کرتا ہے۔ حقیقی GPU تربیت اس CPU راستے سے نہیں گزرتی۔
یہ الگ تجربہ ہے، UrduPy کی بنیادی dependency فہرست میں AI packages شامل نہیں۔

باقیاتی architecture کا اصل حوالہ:
[Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)۔
STL-10 کے لیے اصل dataset مصنفین Coates، Lee اور Ng کا ۲۰۱۱ مقالہ سرکاری صفحے
پر درج ہے۔
