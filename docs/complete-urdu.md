# مکمل اردو میں پروگرامنگ

اردو فائلیں براہ راست چلائیں؛ الگ پائتھن میزبان پروگرام لازم نہیں۔
[دو آزاد اردو ماڈیول](../examples/مکمل_اردو/آزاد_پروگرام.urdu)،
[اصل تصویری ریسنیٹ تربیت](../examples/مکمل_اردو/ایس_ٹی_ایل۱۰/README.md) اور
[محفوظ پچاس دور کے نتائج و گراف](نتائج/ریسنیٹ/README.md) دیکھیں۔

اس انداز میں کتاب خانے، ان کے ارکان، نام والے دلائل، ماڈل کے خاص طریقے اور
متنی اختیارات اردو رسم الخط میں لکھے جا سکتے ہیں۔ اصل حساب اور تربیت نصب شدہ
کتب خانے ہی کرتے ہیں۔ سرنی یا ٹینسر کی الگ نقل اور نئی قسم نہیں بنائی جاتی۔

## آغاز

اپنی فائل کے شروع میں یہ حقیقی تبصرہ رکھیں:

```
# اردوپائی: مکمل
درآمد نمپی
اعداد = نمپی.سرنی([1, 2, 3])
دکھاؤ(اعداد.اوسط())
```

تبصرہ کسی عبارت کے اندر لکھنے سے انداز تبدیل نہیں ہوتا۔ پرانی فائلیں اپنی
موجودہ صورت میں چلتی ہیں۔ ہر الگ درآمد ہونے والی اردو فائل اپنا انداز منتخب
کرتی ہے۔ اردو نشست خود مکمل انداز میں شروع ہوتی ہے۔

## نام تلاش کرنا

```
اردوپائی نام
اردوپائی نام --کتب_خانے
اردوپائی نام نمپی
اردوپائی نام ٹارچ.عصبی
اردوپائی نام ٹارچ.اصلاح
اردوپائی بیٹھک
```

پہلی صورت مانوس اردو لغت دکھاتی ہے اور کتاب خانے درآمد نہیں کرتی۔ ماڈیول کا
نام دینے پر اسی نصب شدہ ماڈیول کے دستیاب ارکان دیکھے جاتے ہیں۔ کسی فنکشن یا
کلاس کا راستہ دینے پر قابل دریافت دلائل بھی دکھائے جاتے ہیں۔ جن مقامی فنکشنوں
کے دستخط دستیاب نہ ہوں، ان کے دلائل کی خودکار فہرست محدود ہو سکتی ہے۔

عام ارکان کے آسان نام ہیں۔ ہر اضافی نام کے لیے `اصل_` سے شروع ہونے والی بالکل
درست املا بھی دکھائی جاتی ہے۔ اس میں اصل نام کے ہر حرف کا عدد اردو ہندسوں میں
لکھا جاتا ہے۔ یوں نئے، نجی اور غیر مانوس ارکان بھی کسی نئی لغت کے انتظار کے
بغیر لکھے جا سکتے ہیں۔ یہ عددی املا ہے، انسانی ترجمے کا دعویٰ نہیں۔

غیر معمولی نام، مثلاً خلا یا خاص علامت والا نام، عبارت کے ذریعے حاصل ہوتا ہے۔
تلاش کا حکم اس کے لیے `خاصیت_لو` اور `اصل_متن` والی تیار صورت دکھاتا ہے۔
انگریزی ہجوں کی الگ نمائش چاہیں تو تلاش کے ساتھ `--اصل` لکھیں۔

## ٹینسر اور ماڈل

```
# اردوپائی: مکمل
درآمد ٹارچ

کلاس چھوٹا_ماڈل(ٹارچ.عصبی.جزو):
    فنکشن آغاز(خود):
        بالائی().آغاز()
        خود.تہہ = ٹارچ.عصبی.خطی(3, 1)

    فنکشن آگے(خود, آمد):
        واپس خود.تہہ(آمد)

ماڈل = چھوٹا_ماڈل().منتقل(مرکزی_آلہ)
دکھاؤ(فہرست(ماڈل(ٹارچ.اتفاقی_معمول(2, 3)).شکل))
```

`آغاز` اصل تعمیری طریقہ بن جاتا ہے اور `آگے` عصبی ماڈل کا اصل پیش قدمی طریقہ۔
وراثت، تدریج، بہترکار، آلات اور محفوظ وزن اصل کتب خانے کے مطابق کام کرتے ہیں۔
`مرکزی_آلہ`، `گرافیکی_آلہ` اور `سرخ_سبز_نیلا` جیسے نام اصل متنی اختیارات دیتے ہیں۔
آلہ دستیاب ہونا اور مناسب تنصیب ابھی بھی متعلقہ کتاب خانے کی شرط ہے۔

## ہر عبارت کی اردو املا

عبارتیں اور تبصرے خود سے تبدیل نہیں ہوتے۔ کتاب خانے کو کسی خاص بیرونی عبارت
کی ضرورت ہو تو `متن_` والی عددی املا کو `اصل_متن` میں دیں۔ مثال کے طور پر:

```
# اردوپائی: مکمل
درآمد ٹارچ
آلہ = اصل_متن("متن_۹۹_۱۱۲_۱۱۷")
اعداد = ٹارچ.صفر(2, آلہ=آلہ)
دکھاؤ(فہرست(اعداد.شکل))
```

یہ طریقہ خالی عبارت، فائل کے راستے، رنگ کے اختیارات، لغت کی کلید اور کسی بھی
مزید عبارت کے لیے کام کرتا ہے۔ نام کی املا اور عبارت کی املا الگ ہیں۔

## اپنی چیزوں کے نام

مکمل انداز کی لغت ایک محفوظ ناموں کی فہرست ہے: ایک ہی نام جہاں بھی آئے،
تعریف، متغیر، خاصیت یا نام والے دلیل میں، اس کی ایک ہی اصل املا بنتی ہے۔ اس
طرح اپنے فنکشن کے دلائل اور ان کی پکار بھی متفق رہتے ہیں۔ ایک اصل نام کے دو
مترادف اردو ناموں کو الگ متغیر نہ سمجھیں۔ لغت سے باہر اپنے صاف اردو نام آزاد ہیں۔
ماڈیول کے آسان نام درآمد کے مقام پر حل ہوتے ہیں اور اصل ماڈیول سے بندھتے ہیں۔

یہ انداز دوسری زبان میں لکھے گئے کتاب خانے کے اصل پیغامات، استثنا، نتائج کی
متنی نمائش، دستاویز یا محفوظ وزن کی اندرونی کلیدوں کو ازخود ترجمہ نہیں کرتا۔
پروگرام کی املا اردو ہوتی ہے؛ بیرونی معلومات کی اصل قدر برقرار رہتی ہے۔

## تنصیب اور چلانا

منصوبہ پہلے اپنے ماحول میں نصب کریں۔ پھر اردو حکم سے متعلقہ مجموعہ نصب کریں:

```
اردوپائی نصب بنیادی
اردوپائی نصب سائنسی
اردوپائی نصب مصنوعی_ذہانت
اردوپائی چلاؤ سلام.urdu
اردوپائی جانچو سلام.urdu
اردوپائی ترجمہ سلام.urdu --مخرج نتیجہ.py
```

یہ مقامی، ابھی غیر شائع شدہ نسخہ منصوبے کے اصل فولڈر سے نصب ہوتا ہے۔ خودکار
درآمد کسی چیز کو نصب نہیں کرتی۔ تنصیب صرف واضح حکم سے ہوتی ہے اور وزن یا
اعدادی مجموعے خود سے نہیں لاتی۔ بنیادی ماحول میں بھاری کتب خانے لازم نہیں۔
