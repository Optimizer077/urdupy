# مکمل اردو میں سائنسی پروگرام

ان مثالوں کی تمام تحریر، درآمدات، جماعتیں، طریقے، دلائل، تبصرے اور پیغامات
اردو میں ہیں۔ ہر ماخذ کی پہلی سطر مکمل اردو انداز منتخب کرتی ہے:

```
# اردوپائی: مکمل
```

یہ اصل عددی اور عصبی کتب خانوں ہی کی اشیا ہیں۔ تہہ، وزن، تدریج، اصلاح کار
اور محفوظ حالت دوسری پائتھن تحریروں کے ساتھ بھی استعمال ہو سکتے ہیں۔
مکمل انداز میں لغت کے مقرر کردہ نام محفوظ ہیں؛ اپنے نئے نام ان سے مختلف رکھیں۔
پرانی ملی جلی تحریریں اپنے معمول کے انداز میں چلتی رہتی ہیں۔

| مثال | کیا کرتی ہے؟ |
|---|---|
| [عددی حساب](عددی_حساب.urdu) | سرنی، عددی قسم، شکل، پھیلاؤ، اوسط اور خطی مساوات۔ |
| [عصبی تربیت](عصبی_تربیت.urdu) | اردو آغاز اور آگے، حقیقی خطی ماڈل، دو اصلاح کار، تدریج، وزن محفوظ کرنا اور بحال کرنا۔ |
| [تصویری حساب](تصویری_حساب.urdu) | مصنوعی رنگین تصویر، سرمئی تبدیلی، حجم بدلنا اور اصل تصویری شے۔ |
| [بصارت اور زبان](بصارت_اور_زبان.urdu) | تصویری تبدیلیاں اور چھوٹا مقامی برٹ ماڈل؛ کسی تیار وزن کی ضرورت نہیں۔ |
| [ریسنیٹ](ریسنیٹ.urdu) | اٹھارہ تہوں کی مکمل باقیاتی بناوٹ، آٹھ بلاک اور دس زمرے؛ آغاز اور آگے دونوں اردو میں۔ |
| [تربیتی خاکہ](تربیتی_خاکہ.urdu) | حقیقی تربیتی نقصان، متصل اردو عنوان، اردو ہندسے اور محفوظ تصویر۔ |

پہلے منصوبے کی [تنصیب کی ہدایات](../../docs/install.md) کے مطابق اختیاری عصبی
کتب خانے نصب کریں۔ پھر منصوبے کے بنیادی فولڈر سے:

```
اردوپائی جانچو مثال.urdu
اردوپائی چلاؤ مثال.urdu
اردوپائی نام ٹارچ
```

اوپر `مثال.urdu` کی جگہ مطلوبہ فائل کا پورا راستہ دیں، مثلاً:

```
اردوپائی چلاؤ examples/مکمل_اردو/عددی_حساب.urdu
اردوپائی چلاؤ examples/مکمل_اردو/عصبی_تربیت.urdu
اردوپائی چلاؤ examples/مکمل_اردو/ریسنیٹ.urdu
اردوپائی چلاؤ examples/مکمل_اردو/تربیتی_خاکہ.urdu
```

تربیت کا نمونہ موجودہ فولڈر میں `سیکھے_ہوئے_وزن` محفوظ کرتا ہے۔ خاکے کا نمونہ
اسی جگہ `تربیتی_نقصان.png` بناتا ہے۔ فائل کی توسیع نظام کے مقرر کردہ نام کی ہے؛
پروگرام میں انگریزی حرف نہیں لکھا گیا۔ خاکہ خام اردو متن کو مقامی حرف سازی
دستیاب ہونے پر براہ راست دیتا ہے؛ پرانے پس منظر میں حروف جوڑ کر ترتیب دیتا ہے۔
اس جانچے گئے ونڈوز ماحول میں اردو خط تاہوما موجود ہے۔

`سکھاؤ("تدریجی")` رفتار کی یادداشت والا تدریجی نزول استعمال کرتا ہے؛
`سکھاؤ("ایڈم")` وزن کے الگ زوال والا ایڈم استعمال کرتا ہے۔ ہر ایک ایک سو بیس
ادوار میں مقامی مصنوعی اعداد سے خطی تعلق سیکھتا ہے۔ یہ سیکھنے اور اصل تدریج کی
مثال ہے، کسی بیرونی مجموعۂ مواد کی درستگی کا دعویٰ نہیں۔

ریسنیٹ کی طے شدہ چوڑائی چونسٹھ ہے اور کل پیرامیٹر ۱۱٬۱۷۳٬۹۶۲ ہیں۔ براہ راست
چلانے کا مختصر نمونہ چوڑائی آٹھ اور مصنوعی تصویریں لیتا ہے تاکہ آگے اور پیچھے کا
حساب جلد ہو۔ پہلے سے مکمل ہو چکی [اصل تصویری تربیت](../../experiments/ریسنیٹ_ایس_ٹی_ایل۱۰/README.md)
کی فائلیں اور نتائج محفوظ ہیں؛ یہاں اس پرانی تربیت کو دوبارہ چلانے کا دعویٰ نہیں۔

ان مثالوں کے لیے کوئی تصویر، مجموعۂ مواد یا تیار وزن ڈاؤن لوڈ نہیں ہوتا۔
مطابقت کی الگ آزمائش اصل پائتھن حساب سے عددی جواب، تدریج، دونوں اصلاح کاروں کے
وزن، بحالی، تصویری نقاط، مقامی زبان ماڈل اور ریسنیٹ کی بناوٹ ملاتی ہے۔
مقررہ لغت سے باہر کسی بھی نئے نام کے لیے `اردوپائی نام` کی واپس بدل سکنے والی
اردو ہجے استعمال کریں؛ اصل کتب خانہ نصب ہونا پھر بھی لازم ہے۔
